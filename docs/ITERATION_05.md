# Iteration 05 — Cinematic light (поверх THE LIVING ESTATE)

## Диагноз ветки
Система le-* цельная, но: первый экран — фото под плотным скримом без световой глубины;
впечатления спрятаны в табы (виден один оффер); секции чередуются только цветом фона;
в living-estate.css два идентичных «fit pass» блока; в финале повторён полный вордмарк.

## Перенесённые принципы (без копирования чужой айдентики)
- Атмосферная глубина и тёплый свет в тёмном первом экране → le-hero-bloom + шов в linen.
- Проявляющийся editorial-текст → Statement (слова из приглушённого в чернильный).
- Цветовой блок на каждый продукт → cx-панели: глина / охра / мох / бирюза, у каждой свой
  акцентный заголовок, блик и CTA; все четыре оффера видны сразу.
- Ритм свет/тьма и мягкие швы между средами → градиентные переходы секций.
- Сдержанная подпись бренда вместо повторного логотипа → только официальная печать + строка места.

## Целостность
Цены — только при подтверждённом флаге; сауна и пакеты — «Manager to confirm»;
часы — только подтверждённые; часы ресторана подписаны как ресторанные;
отзывы не выдуманы; заявка ≠ бронь; BookingFlow, схема, валидация, идемпотентность,
цены, промо, персистентность и outbox не тронуты. Четыре локали сохранены.
